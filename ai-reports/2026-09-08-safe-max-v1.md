# Safe maximum — how far forge can go without leaving the league
Date: 2026-09-08 | base: 2.10.0 (~65/100) | v1
Standing constraints: offline, zero deps, sub-second builds,
single-digit-ms runtime, mobile-safe, minimalism. Standing refusals:
control-flow flattening, VM bytecode, dead-code injection,
debugProtection intervals, HMAC, built-in locks.

## 1. Method
Per category: current score -> safe ceiling, with the concrete mechanism
that earns each point and why it does not violate a constraint. Nothing
here needs a server, a dependency, or runtime slower than one array alloc.
Every item is representation-only (provably same behavior) except where
marked RUNTIME (bounded, measured).

## 3. Innovation catalog (novel or derived-then-reduced)
- **F1 `flow` pass (derived, reduced).** j-obfuscator's controlFlow/simplify
  reduced to a subset provable on tokens alone, zero runtime cost:
  comma-join of expression statements (`a(); b();` -> `a(), b();`),
  negation-flip (`if (!x) {A} else {B}` -> `if (x) {B} else {A}`),
  for/while spelling normalization. Each rule is a local rewrite with no
  scope questions; battery proves each with before/after pairs. (+4)
- **S1 central string table (derived, adapted).** j-obf LOW's
  rotate+shuffle+indexShift, rebuilt for the .fs model: crypt optionally
  emits ONE array + index calls instead of inline `__f` calls, table order
  shuffled per seed, indices shifted per seed. Same values, analyst faces
  one rotated structure instead of scattered literals. Runtime: one array
  alloc (measured, single-digit-ms budget kept). (+1-2)
- **S2 seeded stub identity (forge-original).** The stub already carries its
  key literal per file; extend: stub NAME (`__f` -> seeded `__f3a9`-class)
  and chunk length (fixed 16 -> seeded 8-24) vary per FORGE_SEED. Every
  build has a different decoder shape; default builds stay diffable. (+1,
  counted inside strings 13)
- **N1 scope-aware short (derived, research-grade).** Today only
  single-declaration file-unique names rename (LIMITS L15: cross-scope
  same-name never touched). Bounded scope tracking on the mask (brace
  depth + declaration positions, the poison.py machinery generalized)
  renames shadowed locals per scope. Highest-risk item here: prototype
  behind a flag, battery of shadowing tortures, real-file differential
  before default-on. (+1, plus size gains)
- **Z1 custom-alphabet blobs (derived).** Base64 with a per-seed shuffled
  alphabet for crypt hex / pack blobs: smaller than hex (~1.37x vs 2x)
  AND opaque to `atob`-grepping analysts. Decoder is a tiny lookup (one
  RUNTIME item, bounded). Generalizes rotation from disk-order to alphabet.
  (+1 size, assists strings)
- **T1 gate options + guard recipe (honest tamper).** No self-read theater:
  optional stricter gate thresholds behind a flag (default stays mobile
  safe), plus a documented host-side guard snippet consumers MAY paste
  (developer choice, same legal shape as the locks decision). Tamper 3->5
  without pretending to be what-keyed-MAC-is. (+2)
- **W1 workflow points (cheapest).** Windows CI matrix, tagged releases
  with notes, QUICKSTART example pair, second consumer pinning a VERSION,
  perf re-measurement on the 2.10.0 chain. No code risk at all. (+2)

## 4. Build order (proposed batches)
- 2.11 `flow` (F1) + gate options (T1): text-only, battery-provable.
- 2.12 strings-II (S1 table + S2 stub variance + Z1 alphabet study).
- 2.13 scope-short research (N1, flagged) + workflow round (W1).
- Re-score against this table after each batch; stop a batch the moment
  perf/size budgets move.

## 5. Locks note (decision stands)
Scoreboard zero is a choice, not a miss. If re-opened, the safe shape is
an OPT-IN `--lock domain:` flag (default off, developer's call per script)
worth ~+5. Not queued; listed so the ceiling math stays honest.

## 6. Why 100 stays impossible (restated for this report)
~12 points need full flattening/VM (perf + mobile forbid), ~5 need
intervals/keys (mobile/theater forbid), ~8 need built-in locks (owner
forbids). 78 + 5 (locks) = 83 is the honest maximum of this tool, in this
league, under these rules. Past that begins a different product.
